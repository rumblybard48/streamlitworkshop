# Streamlit Interactive Demo App

This project is an interactive web application built using Streamlit.  
It demonstrates user input handling, basic calculator operations, data visualization, and layout structuring within a simple web interface.

---

## Overview

The application includes:

- User greeting functionality
- Age selection using a slider
- Button interactions
- A basic calculator (Add, Subtract, Multiply, Divide)
- Line chart visualization using Plotly
- Layout design with columns and expandable sections
- Markdown and HTML rendering

---

## Features

### User Interaction
- Accepts text input
- Displays dynamic greetings
- Age selection with slider
- Interactive button responses

### Calculator
- Addition
- Subtraction
- Multiplication
- Division

### Data Visualization
- Line chart generated using Plotly Express
- Embedded directly within the Streamlit interface

### Layout Components
- Two-column layout
- Expandable content section
- Markdown and HTML formatting support


- Python
- Streamlit
